## Why ResumeSkills?

75% of resumes are rejected by Applicant Tracking Systems before a human ever reads them. Most job seekers apply broadly with generic materials, write bullets without metrics, and enter salary conversations unprepared. ResumeSkills fixes all of this by equipping your AI assistant with the exact frameworks recruiters and hiring managers look for.

## Available Skills

ResumeSkills ships 20 skills across five categories:

### Resume Optimization
| Skill | What it does |
|-------|-------------|
| `resume-ats-optimizer` | Pass ATS systems with keyword and format analysis |
| `resume-bullet-writer` | Transform weak bullets into achievement-focused statements |
| `resume-quantifier` | Add metrics and numbers to every achievement |
| `resume-formatter` | Clean, scannable, ATS-friendly formatting |
| `resume-section-builder` | Targeted sections for different experience levels |

### Job Search Strategy
| Skill | What it does |
|-------|-------------|
| `job-description-analyzer` | Calculate match scores, identify gaps, build application strategy |
| `resume-tailor` | Customize resume for each job while staying truthful |
| `resume-version-manager` | Track master and tailored resume versions |
| `offer-comparison-analyzer` | Compare total compensation side-by-side |

### Supporting Documents
| Skill | What it does |
|-------|-------------|
| `cover-letter-generator` | Personalized cover letters from resume + job description |
| `linkedin-profile-optimizer` | Sync resume with LinkedIn and optimize for search |
| `portfolio-case-study-writer` | Turn bullets into detailed portfolio case studies |
| `reference-list-builder` | Format and prepare professional references |

### Interview & Negotiation
| Skill | What it does |
|-------|-------------|
| `interview-prep-generator` | STAR stories, practice questions, company-specific prep |
| `salary-negotiation-prep` | Market rates, negotiation strategy, counter-offer scripts |

### Specialized Roles
| Skill | What it does |
|-------|-------------|
| `tech-resume-optimizer` | Engineering, PM, and technical role optimization |
| `executive-resume-writer` | C-suite and VP-level leadership resumes |
| `academic-cv-builder` | CVs with publications, grants, and teaching experience |
| `creative-portfolio-resume` | Balance visual design with ATS compatibility |
| `career-changer-translator` | Identify and translate transferable skills |

## Get Started

<Steps>
  <Step title="Install all 20 skills globally">
    ```bash
    npx skills add Paramchoudhary/ResumeSkills -g -y
    ```
  </Step>
  <Step title="Open your AI assistant">
    Launch Claude Code, Cursor, or your preferred AI coding assistant in any project.
  </Step>
  <Step title="Ask for help with your resume">
    ```
    "Optimize my resume for ATS" — uses resume-ats-optimizer
    "Improve my resume bullets" — uses resume-bullet-writer
    "Write me a cover letter for this role" — uses cover-letter-generator
    ```
  </Step>
  <Step title="Iterate and apply">
    Work through the skills in sequence — optimize, tailor, write supporting documents, then prep for interviews.
  </Step>
</Steps>

<Tip>
  Install globally with `-g` so the skills are available in every project, not just the current directory.
</Tip>
